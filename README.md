# lY Docs

lY Docs is a Phase 1 frontend-only smart document builder built with Next.js,
TypeScript, Tailwind CSS and Framer Motion.

## Getting Started

Install dependencies:

```bash
npm install
```

Run the local development server:

```bash
npm run dev
```

Open `http://localhost:3000`.

## Phase 1 Includes

- Landing page
- Login UI
- Register UI
- Dashboard
- Create Document page
- Document Builder page
- Editable A4 canvas
- Draggable document blocks
- Logo upload preview

No backend, database, real login, payment or real AI integration is included yet.
